# Shell config

## Ownership

```
~/.bashrc     user-owned, long-lived HPC/Phylanx/spack/cactup settings
                 must contain: source ~/.bashaux
~/.bashaux    GENERATED by install.py — do not hand-edit
bin/workenv-platform.sh   sourced by ~/.bashaux and by install/mk-*.sh
```

`install.py` appends `source ~/.bashaux` to `~/.bashrc` if missing. It does not rewrite the rest of bashrc.

## What `~/.bashaux` does

- Sets `WORKENV_ROOT`, redetects `WORKENV_PLATFORM`, sets `WORKENV_PREFIX`
- Sets `PYTHONUSERBASE` (see [platform.md](platform.md))
- Optionally activates `~/venv` if present
- `set -o vi`
- Prepends `$(workenv_compatible_bin_path):$WORKENV_ROOT/bin:$HOME/bin` to PATH, appends `$PYTHONUSERBASE/bin`
- Adds `$WORKENV_ROOT/py` to `PYTHONPATH`
- Aliases: `vi=vim`, `pip3='python3 -m pip'`, `envup`, spack helpers, …
- Locale: `en_US.UTF-8` if the locale archive has it, else `C.UTF-8`, else `C` (missing `en_US.UTF-8` spams bash-completion)
- `VISUAL=$(command -v vim)` after PATH is set
- Unlimited bash history, shared across shells via `PROMPT_COMMAND` (`history -a; history -n`)
- Sources `bin/long-cmd-notify.sh` (hourglass in the terminal title for long commands)
- Sources grok bash completions from `~/.grok/completions/bash/grok.bash` if present (binaries themselves live in the prefix)

## `envup`

Defined in bashaux:

```
envup [install.sh flags...]
```

`cd $WORKENV_ROOT && git pull && ./install.sh "$@" && source ~/.bashrc`.

`install.sh` prompts on `/dev/tty` (`[y/N]`, default no) for Python and Vim so `git pull` / non-TTY stdin cannot swallow the questions.

```
envup -y                 # no prompts, install everything
envup --skip-python
envup --skip-vim
envup --force-python
WORKENV_YES=1 envup
```

## PATH order gotcha (this machine)

`~/.bashrc` sources bashaux **then** prepends perl5, cargo, and spack. Those can shadow workenv binaries. That is user bashrc, not bashaux. If `which python3` or `which vim` is unexpected, print PATH and look above `$WORKENV_PREFIX/bin`.

Workenv **does not** put these on PATH:

- `~/.local/bin` (commented out in bashrc on purpose)
- `~/.grok/bin` (official grok installer tries to add this; workenv strips the block)

## Do not re-add the grok installer snippet

```
# >>> grok installer >>>
export PATH="$HOME/.grok/bin:$PATH"
# <<< grok installer <<<
```

`install.py` and `grok-install.sh` delete that block. Putting it back makes grok bypass the platform prefix and confuses container PATH.
